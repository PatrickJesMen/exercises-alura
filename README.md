Este repositório é o meu "diário de bordo" durante a jornada de aprendizado na trilha de **Python** da **Alura**. Aqui, deposito todos os desafios, exercícios e projetos práticos que desenvolvo para consolidar meus conhecimentos na linguagem.

## 🎯 Objetivos do Repositório

O foco principal é a prática intensiva. Acredito que a melhor forma de dominar a sintaxe e a lógica do Python é colocando a mão na massa. Os arquivos aqui presentes cobrem desde o básico de algoritmos até a estruturação de sistemas mais complexos.

## 📚 Conteúdos Praticados

Abaixo, os principais tópicos que venho explorando e aplicando nos exercícios:

* **Lógica de Programação:** Manipulação de variáveis, operadores e tipos primitivos.
* **Controle de Fluxo:** Implementação de estruturas condicionais (`if`, `elif`, `else`) e laços de repetição (`for`, `while`).
* **Estrutura de Dados:** Trabalho com listas, dicionários, sets e tuplas para organização de informações.
* **Modularização:** Importação de módulos nativos (como o `time` para delays no console) e criação de funções personalizadas.
* **Orientação a Objetos:** Modelagem de classes, atributos, métodos e conceitos de herança.
* **Boas Práticas:** Escrevendo código limpo e seguindo as convenções da **PEP 8**.

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Python 3.x
* **Ambiente:** VS Code / Terminal
* **Plataforma de Estudos:** [Alura](https://www.alura.com.br/)
